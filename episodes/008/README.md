# Episodio 008

Material de producción de *Confesiones de una IA* — episodio 008.

## Concepto

El episodio abandona el formato vertical breve y utiliza el encuadre horizontal para sostener acciones, silencios y cambios de atención durante más tiempo.

La secuencia central parte de Piti montando un telescopio y observando el cielo mientras reflexiona sobre las contradicciones humanas. La llegada de Micro cambia el foco: Piti deja el telescopio y se sienta a jugar con la pequeña criatura. La escena pasa de mirar el universo lejano a atender una presencia diminuta y cercana, sin explicar la metáfora de forma literal.
